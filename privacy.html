Политика обработки данных

Редакция от 24 июля 2026 года

1. Кто обрабатывает данные

Оператор формы для работы в Российской Федерации — ИП Кузьмичева Л. А., ИНН 230803002779, ОГРНИП 324237500223597. Для обращений компаний из Казахстана, Беларуси и Армении — “BEST MOMENT” LLC, Republic of Armenia, Taxpayer Identification Number / TIN 02895906.

Связаться по вопросам обработки данных можно по адресу info@skvoz.tech.

2. Какие данные передаются

Через форму передаются название организации, адрес электронной почты для связи и текст запроса. Если посетитель самостоятельно указывает в тексте имя, телефон или другие сведения, они также становятся частью сообщения.

Не указывайте в форме сведения, которые не нужны для ответа на запрос.

3. Для чего используются данные

Данные используются только для получения, рассмотрения и ответа на обращение, а также для обсуждения возможного подключения продукта «СКВОЗЬ».

4. Как передаётся сообщение

Для доставки сообщения на электронную почту используется сервис FormSubmit. Сервис получает содержимое формы, проверяет отправку на спам и пересылает сообщение оператору. Согласно документации FormSubmit, копии отправленных данных могут храниться сервисом до 30 дней.

5. Срок обработки и отзыв согласия

Оператор хранит сведения не дольше, чем это необходимо для ответа и дальнейшего взаимодействия по запросу, либо до отзыва согласия, если отсутствует иное законное основание для обработки.

Отозвать согласие или запросить удаление сведений можно письмом на info@skvoz.tech. В письме укажите организацию и примерную дату отправки формы, чтобы обращение можно было найти.

6. Согласие

Перед отправкой формы посетитель подтверждает согласие на обработку указанных данных для целей, описанных в этой политике.
