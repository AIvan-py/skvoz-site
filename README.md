## Сайт

`index.html` — статический маркетинговый сайт продукта. Он сделан без сборки и серверной части, поэтому подходит для GitHub Pages.

Текущие ограничения перед публичным запуском:

- в метаданных, `robots.txt` и `sitemap.xml` указан выбранный домен `https://skvoz.tech/`; перед публикацией его нужно зарегистрировать;
- адрес `info@skvoz.tech` нужно создать после регистрации домена;
- форму обратной связи нужно один раз активировать после создания адреса `info@skvoz.tech`;
- PDF-презентация не опубликована, потому что актуальный PDF нужно сформировать заново после финальной публичной редакции;
- реальные скриншоты из `assets/screenshots/` не встроены в сайт, пока они не обезличены.

## Форма обратной связи

Форма на главной странице использует бесплатный сервис FormSubmit и не требует серверной части. Обязательные поля: название организации, электронная почта для связи и текст запроса. Адрес электронной почты также используется как адрес для ответа на полученное сообщение.

После создания доменной почты и первой публикации:

1. Отправить тестовый запрос через форму на опубликованном сайте.
2. Открыть письмо активации, пришедшее на `info@skvoz.tech`.
3. Подтвердить форму по ссылке из письма.
4. Отправить второй тестовый запрос и проверить доставку, папку «Спам» и переход на `thanks.html`.

До подтверждения FormSubmit будет отправлять письма активации вместо обычных уведомлений. Для защиты от простого спама включены стандартная CAPTCHA сервиса и скрытое поле-ловушка.

`privacy.html` содержит базовую политику обработки данных для формы. Перед публичным запуском её нужно проверить с юристом с учётом фактической схемы работы и используемого почтового сервиса.

## Бренд

- `assets/brand/skvoz-logo-full.png` — полный горизонтальный логотип с названием, дескриптором и слоганом; используется в шапке сайта и презентационных материалах.
- `assets/brand/skvoz-mark-compact.png` — компактный знак порталов на прозрачном фоне; вариант для favicon, мобильной иконки, аватара и тёмного футера.
- `assets/brand/source/skvoz-mark-compact-chroma.png` — технический исходник компактного знака до удаления фона; не публикуется на сайте.

## Презентация

`presentation/index.html` — каноническая интерактивная презентация. Она автономна: изображения слайдов встроены в HTML, поэтому файл открывается без папки со скриншотами.

`downloads/skvoz-orders-2026-07.html` — копия презентации для скачивания. Обновляется командой:

```bash
node scripts/sync-presentation.mjs
```

## Скриншоты

`assets/screenshots/` содержит исходные изображения интерфейса для сайта и дальнейшей публичной редакции.

Перед публикацией необходимо заменить реальные названия клиентов, поставщиков, номера заказов, цены и другие чувствительные сведения на демонстрационные данные. Наличие файлов в этой директории не означает, что они уже безопасны для открытого сайта.

## План

Актуальная концепция бренда, структура сайта, правила мобильной версии и требования к публикации находятся в `plans/PLAN_SKVOZ_MARKETING_SITE_20260724.md`.

## GitHub Pages и собственный домен

Можно разместить эту директорию как статический сайт на GitHub Pages:

1. Создать отдельный GitHub-репозиторий для сайта.
2. Загрузить содержимое директории `marketing-site` в корень репозитория.
3. Включить GitHub Pages из ветки `main`, папка `/`.
4. После покупки домена создать файл `CNAME` рядом с `index.html` и вписать туда `skvoz.tech`.
5. У регистратора домена настроить DNS на GitHub Pages.
6. В настройках GitHub Pages включить HTTPS после проверки домена.

Файл `CNAME.example` оставлен как шаблон. Его нельзя публиковать как `CNAME`, пока фактический домен не выбран.
