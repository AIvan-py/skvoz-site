# Комплект оформления писем СКВОЗЬ

Папка находится рядом с презентацией и содержит облегчённые файлы для деловой переписки. Исходный большой логотип в письмо вставлять не нужно: он тяжелее и содержит слишком много пустого поля.

## Что использовать

- `skvoz-logo-horizontal.png` — горизонтальный логотип для верхней части письма или документа. Рекомендуемая ширина в письме: 260–320 px.
- `skvoz-mark-email.png` — компактный знак на прозрачном фоне. Рекомендуемая ширина: 64–82 px.
- `skvoz-avatar-512.png` — основной квадратный аватар для почтового профиля и сервисов. Загружать без дополнительной обрезки.
- `skvoz-avatar-128.png` — облегчённая версия аватара для сервисов с ограничением размера.
- `skvoz-divider.png` — фирменная синяя линия. В HTML-письмах лучше делать линию цветом `#2F6BFF`, а не картинкой.
- `signature.html` — готовая подпись с небольшим знаком, телефоном, почтой и сайтом.
- `email-template.html` — нейтральный фирменный бланк. Текст внутри является заполнителем и должен быть заменён перед отправкой.

## Публичные адреса после публикации сайта

- `https://skvoz.tech/email-brand-kit/skvoz-mark-email.png`
- `https://skvoz.tech/email-brand-kit/skvoz-logo-horizontal.png`
- `https://skvoz.tech/email-brand-kit/skvoz-avatar-512.png`

Изображения в HTML-подписи уже подключены по этим адресам. Пока сайт открывается без HTTPS, некоторые почтовые клиенты могут блокировать картинки. Использовать подпись лучше после включения `Enforce HTTPS` в GitHub Pages.

## Практический совет

Для первого обращения лучше использовать почти текстовое письмо: небольшой знак или логотип, короткий текст, одна ссылка и подпись. Большие баннеры, несколько кнопок и лишние изображения повышают вероятность попадания холодного письма в папку «Спам».
